# 抽奖转盘 · 使用说明

## 一、怎么打开

### 桌面版（推荐）

1. 拿到 `DaFeiYuWheel-x.y.z-portable.exe`（单文件绿色版）。
2. **双击就能用** —— 不需要安装、不需要管理员权限、不会写注册表。
3. 想放到桌面：右键 exe → **发送到** → **桌面快捷方式**；也可以直接拖到任务栏固定。
4. 窗口大小和位置会自动记住，下次打开还是上次的样子。

> 第一次启动会有 1~2 秒准备时间（免安装版解压自身），之后是秒开。

### 网页版

- 直接双击 `src/index.html`（用浏览器打开），或者用任意静态服务器托管 `src/` 目录。
- 手机上也能玩：把 `src/` 里的三个文件一起发到手机，用手机浏览器打开 `index.html`。
- 网页版和桌面版功能完全一样，数据分别保存在各自的浏览器/应用里。

## 二、怎么用

### 抽奖

- 点中间黑色 **「点击旋转」** 按钮开始：转盘先快后慢转 5~7 圈（约 5 秒），
  停住后指针指着哪个奖品，**才**弹出中奖信息（带彩带和音效）。
- 中奖弹窗里点「再来一次」可以直接接着抽。
- 也可以按键盘：`空格` 或 `回车` = 开始旋转。
- 旋转过程中不能改奖品（会提示「转盘正在旋转，稍等一下」），停稳后即可继续编辑。
- 左上角喇叭图标：开 / 关音效（转动的哒哒声 + 中奖提示音）。

### 添加 / 修改奖品和权重

点右下角圆形 **笔形按钮**（或右上角列表按钮），打开「奖品与权重」面板。
每一行就是一个奖品：

| 控件 | 作用 |
| --- | --- |
| 彩色圆点 | 点一下给这个奖品换颜色 |
| 名称框 | 直接改名字（最多 12 个字） |
| 权重框 | 填数字，越大越容易中；支持小数，如 `0.5` |
| 右侧百分比 | 自动算好的中奖概率，所有奖品合计 100% |
| 红色 ✕ | 删除这个奖品 |

- 「＋ 添加奖品」新增一行。
- 改完点「完成」（或点面板外面的灰色区域）关闭，改动立刻生效。

### 权重怎么理解

- **只看比例，不看数值大小**：`A=10、B=5`，A 的中奖概率是 B 的 2 倍（66.7% : 33.3%）。
- 全部填 `1` = 完全等概率。
- 想设置「某个必中」：把它权重调大、其他项调小即可。
- 权重太小的奖品扇区会很窄，这是正常的（概率就是低）。

### 最近结果 / 恢复默认 / 备份

- 面板下方「最近结果」记录最近抽到的 8 次，可一键清空。
- 「恢复默认」回到最初的 `Lv0 ~ Lv6·Lv6闪电` 一套配置。
- 「导出配置」把当前奖品和权重存成 json 文件；换电脑 / 换浏览器时用「导入配置」读回来。

### 快捷键

| 按键 | 作用 |
| --- | --- |
| `空格` / `回车` | 开始旋转 |
| `Esc` | 关闭设置面板 / 关闭中奖弹窗 |
| `F11` | 全屏 / 退出全屏（桌面版） |
| `F12`、`Ctrl+R` | 开发者工具、刷新（仅 `npm run dev` 开发模式） |

## 三、数据保存在哪

- 奖品、权重、颜色、音效开关、抽奖记录都自动保存在**本地**（桌面版存在应用数据目录，网页版存在浏览器 localStorage）。
- 不联网、不上传，清理浏览器数据或卸载应用会一起清掉。
- 重要的抽奖配置请先用「导出配置」备份一份。

## 四、常见问题

- **双击 exe 没反应？**
  1. 个别杀毒软件会拦截未签名的陌生 exe，选择「允许运行」即可；或者改用网页版。
  2. 如果你是**右键 →「以管理员身份运行」**打开的，Chromium 的沙箱在部分系统上会初始化失败、
     程序直接静默退出。这种情况请用同目录的 `兼容模式启动.bat`（它会自动加 `--no-sandbox` 参数），
     或者普通双击（不要用管理员身份）即可。
- **页面显示很小或很大？** 按住 `Ctrl` 滚动鼠标滚轮调整缩放（网页版），桌面版可用 `F11` 全屏。
- **奖品超过 10 个时文字变小？** 这是自动适配，特别小的扇区会省略文字；把权重调大扇区就宽了。
- **换电脑后配置丢了？** 用「导出配置」/「导入配置」迁移。

## 五、文件说明

| 路径 | 说明 |
| --- | --- |
| `src/` | 网页版全部内容（`index.html` + `styles.css` + `app.js`），零依赖 |
| `electron/main.js` | 桌面版外壳：窗口、图标、快捷键、窗口尺寸记忆 |
| `build/` | 应用图标 |
| `dist/` | 打包产物（`npm run dist` 后生成） |
